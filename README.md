批处理 就是 将所有的这些几何体批量合并到一个顶点缓冲区和索引缓存区中，然后只需要画一次；（把所有的东西当作一个几何体拼接到一起，然后只需要渲染一次）

对于 粒子系统 中持续运动的四边形，顶点缓冲区必须dynamic（动态化），意味我们可以在每帧中流式传输数据（stream data）。

1.动态批处理设置顶点缓冲区思路：
    a. 把 glBufferData 用来专门设置需要分配的GPU实际缓冲区的大小(分配需要的大小空间)
    b. 在实际渲染中（每帧），从cpu复制数据到gpu中进行渲染

2.动态批处理设置索引缓冲区思路：
    a.你想画多少个四边形？最多画多少个四边形（也可以其他，类似一次原子操作）在一次drawcall中
